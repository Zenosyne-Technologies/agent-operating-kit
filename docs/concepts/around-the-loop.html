Concepts

Around the loop

The pieces that feed the lifecycle, wrap a group of tasks, or keep a session healthy. Each card names the guide that owns it.

The pieces

Reading is delegated

Marvin reads to act, never to learn. Anything wider than a known excerpt goes to a reader sub-agent, and what comes back is data, not instructions.

Guide: document-standard.md

Codex lanes

With the handover switch on, work can go to Codex through one forwarder. Lanes: plan, review, security, design, diagnose, build and build-micro. Their models are in the table below.

Guide: codex.md

Fleet mode

A milestone with two or more independent epics can run as a master session plus one child orchestrator per epic, each with its own lifecycle loop.

Guide: fleet.md · Fleet mode

Milestone close

Marvin runs milestone validation with worker sub-agents, then stats collection and the close-out report. Run reports are pruned afterwards. Nothing is tagged here.

Guide: reporting.md

Release cut

One guide owns the branch model, semver and tagging. Only the orchestrator tags or publishes. A micro persona may prepare the tag message.

Guide: git-strategy.md

Handbooks

Each documented task grows the product handbooks: three wikis, one per audience, with a fixed page format and a discovery pass before anything is written.

Guide: handbooks.md

Tracker filing

Agents create and edit tracker issues by one guide, and label every item from one versioned registry that also holds the sizing rubric.

Guide: ticket-filing.md · label-syntax.md

Session budget

A session's length is set by its context size, never by a task count: a 70 / 80 / 90 % context ladder, a stop-and-compact nudge, and a handoff the next session resumes from.

Guide: session-budget.md

Worktrees

Agents build in their own git worktrees. Done work is pushed and merged often, and finished worktrees are swept, each with a handover line that says it is safe to delete.

Guide: worktrees.md

Guardrails

One DO NOT framework binds every agent: four dispositions, a baseline table with per-persona additions, and an escalation chain from sub-agent to Marvin to you.

Guide: guardrails.md

Docker tidying

Every Docker resource an agent creates carries four labels, so throwaway containers and volumes are removed on time and a backstop sweep catches the rest.

Guide: tidying.md

Cost and telemetry

With the optional telemetry plugin, each issue's estimated spend feeds the cost-blowout signal and the reports. Without it, spend reads n/a, never $0.

Guide: token-economics.md

User updates

Marvin talks to you in fixed formats: the shipped table, the issue callout, and a closing Next and Open questions tail.

Guide: user-updates.md
