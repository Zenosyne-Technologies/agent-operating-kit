Settings

Marvin is configured in the frontmatter of .marvin/PROJECT-INFO.md. Install writes the file; every key below is one line in it. A key marked optional ships commented out; remove the # to use it.

Set at install

Facts about the project that install fills in from the repository and your answers. They describe the project more than they steer Marvin.

KeyValueDescription
projectset at installThe project's name, as it appears in the headings and reports Marvin writes.
descriptionset at installOne sentence on what the project is for.
briefset at installThe project's own short answer to "what are you building?", kept in the user's words.
ownerset at installThe organisation or person who owns the project.
pm_toolset at installThe tracker Marvin files and reads work in: Linear, Jira, GitHub Issues or the self-contained Local tracker. You choose it at install; it is never guessed.
tracker_coordinatesset at installWhere the project lives in that tracker, such as the site URL and project, the team, or the owner and repository.
project_keyset at installThe key that prefixes the project's ticket ids and commit messages, or n/a when the tracker has none.
hierarchy_levelsset at installHow many levels the tracker offers above a task (milestone, epic, story), which tells Marvin when it must fake a milestone with a virtual one.
intake_guide_urlset at installA link to the Issue Intake & Triage Guide that install writes into the tracker.
stackset at installThe languages, frameworks and data stores the project uses.
dev_commandset at installThe command, and the ports, that start the project's development stack.
audienceset at installWho the project is for: personal, intra-team, restricted-public or public. It shapes how much security and polish the work needs.
project_sizeset at installThe project's estimated size, from tiny to huge. It sets how heavy the surrounding process gets.
app_typeset at installThe kind of application: web, desktop, mobile or a combination.
screens_guideset at installWhere the UI screen catalog lives, the list of surfaces that design and visual review check against.
visual_validationset at installWhen a UI task gets a visual review: after every task, once per milestone, or never.
model_profileset at installThe model profile the project runs, which decides the model behind each tier. Install asks which one.
docs_locationset at installThe folder that holds the project's documentation estate. It is .docs unless you move it.
issue_log_pathset at installThe file where the running build's real bugs are logged, next to the tracker ticket.
telemetryset at installWhether the optional token-telemetry plugin records usage for this project (enabled or disabled).
security_rulesset at installWhether the security advisor and validators add the Project CodeGuard rules on top of the kit's own checklist: kit (the default, also when absent or unknown) or codeguard. Install offers CodeGuard and sets codeguard only on a yes.
kit_versionset at installThe Marvin version this project was installed or last upgraded to. The upgrade skill keeps it current.
label_syntax_versionset at installThe version of the label registry the project's tracker labels follow. The upgrade skill keeps it current.
