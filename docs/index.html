The task lifecycle

Every tracker task runs this loop. A task needs a verifiable definition of done (DoD) before it can enter build, builders work to it and validators try to falsify it.

On a narrow screen, scroll the diagram sideways.

Before build: size decides who works

The size: label and how complete the brief is route each task to a tier. Bigger tasks get extra planning passes first.

When a build is stuck: the escalation staircase

Only build work climbs. Marvin reads the failure pattern after each failed round, never a bare count. Effort rises within a tier first, then the task moves to the next tier, and never above the orchestrator's model without asking you.

Still stuck on the last rung: stop. The ladder ends, never loops back down. The full attempt history goes on the tracker issue and Marvin brings it to you.
