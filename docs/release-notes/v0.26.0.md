# v0.26.0 — play scenarios you can trust to stop, a corrected licence, and a local-path gate

**Marvin learns to play.** `/marvin:play <scenario>` runs a single sub-process of the Marvin workflow on its own, as a bounded, self-terminating scenario. Five ship: `research-solo` (one topic, one researcher), `research-deep` (fan out researchers across aspects, cross-validate, assemble one report), `quick-fix` (one small fix, with a `size:s` ceiling that stops and files a task if it grows), `taskforce` (a mini-lifecycle with a mandatory devil's-advocate pass that the run cannot close positive without), and `bug-hunt` (adversarial hunters with distinct angles that find and report weaknesses). Every scenario declares a GOAL, numeric LIMITS, and both a positive AND a negative exit before it dispatches anything, so it can NEVER run an unbounded loop; a shared contract owns those mechanics plus a periodic report the orchestrator reads between rounds to close a looping or overrunning run gracefully. `bug-hunt` is find-and-report only — it never attacks, exploits, touches a live system, or makes a state-changing call to prove a finding, a rule owned by the contract and the installed `security.md`/`guardrails.md`. It all ships with the plugin (a single `/marvin:play` command plus a `scenarios/` folder it reads), so it costs the installed payload nothing. Agent-teams behaviour is present as a dormant seam that a later Milestone E will activate; today every scenario runs in sub-agent mode.

**The licence holder is now Emprove Services Kft.** The copyright/licence holder across the LICENSE, the installed `.marvin/LICENSE`, the contributor grant in CONTRIBUTING, and the README is corrected from ZENOSYNE Kft. to **Emprove Services Kft. (maintained by Zenosyne Kft.)** — matching the plugin author and the marketplace owner already declared as Emprove. The PolyForm Noncommercial 1.0.0 body is byte-identical; only the copyright notice changed. An upgrading install picks this up when the kit-owned refresh re-renders `.marvin/LICENSE`.

**A contributor's local path can no longer reach the repo.** A twelfth static-gate check, `no-local-paths`, fails the build if any tracked file embeds a local home path (`/Users/<name>` or `/home/<name>`), allowing only the intended `/Users/me` documentation placeholder. It scans the whole repo, not just the payload. Alongside it, the existing local username that had reached the public history was scrubbed from all history with `git-filter-repo` and the release tags were re-pointed — so the reference is gone from HEAD and history, not merely from the tip.

**For consumers**: `upgrades/v0.26.0.md` is the whole upgrade. Nothing moves or is renamed, so this release ships no migration script; the play commands arrive with `claude plugin update marvin`, the corrected licence arrives when `.marvin/LICENSE` is refreshed, and there is nothing to merge into `CLAUDE.md`.
