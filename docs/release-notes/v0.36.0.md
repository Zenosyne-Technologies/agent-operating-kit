# v0.36.0 — Claude 5.5 routing, safe updates, what's new

**Consumers act once:** run `claude plugin update marvin`, follow the update procedure the SessionStart notice prints, then `/marvin:upgrade-agent-os` and start a new session so the refreshed rules, personas and hooks load (`upgrades/v0.36.0.md`).

**Routing for Claude 5.5.** Opus 5.5 orchestrates; Sonnet 5.5 and Haiku 5.5 run their personas pinned to high effort. A new micro-tier developer, `marvin:developer-micro` (Haiku 5.5), builds anything whose brief passes the fully-specified test: a small task, a peripheral piece or a correction with an exact fix list. Work that needs judgement stays with `marvin:developer-small`, and `briefing.md` now says how to write a brief that qualifies.

**The climb.** A stuck build climbs effort within its tier, then tiers up toward the orchestrator's model, never above it by default: micro, small, a new `marvin:escalation-small-xhigh` rung (Sonnet 5.5 at xhigh), then the Opus rungs. A micro-tier stop on a choice the brief did not make is a mis-tiering, not a failed round.

**The update procedure.** The SessionStart notice for a newer Marvin now carries the safe order: finish running tasks, start a new session with no agents working, upgrade, start a new session again. The kit core tells Marvin to relay it as given and never to start an upgrade while agents are working.

**Context budget.** Session length is governed by context size. A plugin hook advises, never blocks: past 400k tokens Marvin is told the work has grown big and suggests a fresh session at the next clean break; past 700k it starts no new task first. A project moves the budgets with `session_soft_ktokens` and `session_hard_ktokens` in `.marvin/PROJECT-INFO.md`. Without the hook, the kit core falls back to a fresh session at milestone close.

**CHANGELOG and what's new.** `CHANGELOG.md` is now categorised from v0.22.0 on (Action needed, Added, Changed, Fixed, Removed, Security), and `validate-kit.sh` refuses an uncategorised bullet. `/marvin:whats-new` aggregates the sections between your installed version and the latest, Action needed first.
