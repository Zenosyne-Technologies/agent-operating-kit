# v0.44.0 — CodeGuard security rules

**Consumers act once:** run `/marvin:upgrade-agent-os`. It asks once for `security_rules: kit | codeguard`; no answer writes `kit` and installs nothing. See `upgrades/v0.44.0.md`.

**Why.** The kit's security checklist is short and generic. Project CodeGuard (CoSAI / OASIS, CC BY 4.0) is a maintained, industry-backed set of security rules that ships as a Claude Code plugin. Teams that want it now get it in the review loop, added on top of the kit's checklist, without the kit copying third-party rules and without making them mandatory.

**What changed.**
- `security_rules` is a new `PROJECT-INFO.md` key. Install (step 6e) and upgrade ask once (no answer or unattended: `kit`); `project-info` validates it; `/marvin:info` reports it with the CodeGuard status. A yes installs `codeguard-security@project-codeguard` at project scope, pinned to v1.5.0, so teammates are offered it too; it is active from the next session. A failed install writes `kit` and the install continues; a re-install keeps a committed value.
- `.marvin/agents/codeguard.md` is the one owner of how the kit uses CodeGuard:
  - availability — one notice per session when the plugin is missing, then the kit checklist alone, never a FAIL;
  - rule selection — the brief names the three always-apply rules plus the topic rules whose tags match the task, within the stack's language row, never the whole row;
  - builders load only the named rules; the security validator checks them and the always-apply rules, and may scan the rest of the row for notes;
  - precedence — CodeGuard adds checks and never softens a kit rule; grading by the kit's severity scale; license — rules are named, never copied.
- The Codex security lane receives the named and always-apply rules as a transient `### Rules` block, so both validators grade the same rules the same way.
- Factory: `scripts/marvin-codeguard.sh` (read-only status check) with `scripts/test-codeguard.sh`; `mh_enabled_plugins` in the hook library, shared with the style-plugin finder; `validate-kit` check `codeguard-grading` (27 checks); the new suite runs in CI (20 suites).
- Docs site: a CodeGuard concept page, a Home card, a Getting started entry and the `security_rules` Settings entry.
