# v0.37.0 — agent worktree cleanup and push cadence

**Consumers act once:** run `claude plugin update marvin`, follow the update procedure the SessionStart notice prints (`upgrades/v0.37.0.md`). Upgrade promptly: the personas and the sweep ship with the plugin, so they act as soon as it updates, even before `/marvin:upgrade-agent-os` installs `worktrees.md`.

**The sweep and its guards.** A plugin hook now removes finished agent worktrees under `.claude/worktrees/` at every session start, and `/marvin:clean-worktrees [--check]` does the same on demand. It keeps a worktree unless all seven guards hold: it is unlocked, no session stands in it, no other worktree or git repository lies inside it, nothing changed in it for 15 minutes, no merge or rebase is in progress, it is clean, and its commits are in a branch other than its own. Prunable entries are reported and left untouched. The local branch is deleted only when origin's copy contains the worktree's commits; otherwise it is kept and reported, and remote branches are never deleted. One accepted limit: a quiet interactive `--worktree` or desktop session standing in a clean, merged worktree under `.claude/worktrees/` can be swept by another session's sweep.

**Push cadence.** Every sub-agent that commits work, the documenter and ponytail included, pushes its own branch before its final message and never force-pushes or pushes `main`, `develop` or a tag. The orchestrator merges a passing branch into its parent and pushes the parent at once. `main` and tags still move only in the release cut. With no remote configured, or a push refused, the push is skipped and said so.

**The handover line.** A committing sub-agent ends its final message with a `WORKTREE:` line: pushed and safe to delete once merged, not pushed with the reason, or none. The orchestrator's handoff in `.marvin/MEMORY.md` lists every worktree it leaves as safe to delete or not safe with the reason, so the next orchestrator and the sweep act on facts. The rules live in the new `.marvin/agents/worktrees.md`, and `.claude/worktrees/` joins `.gitignore`.
