# v0.38.0 — hook-based rule enforcement

**Consumers act once:** run `claude plugin update marvin`, follow the update procedure the SessionStart notice prints (`upgrades/v0.38.0.md`).

**The output style.** A Marvin output style, `marvin:marvin`, carries the user-update rules in the model's system prompt. Install and upgrade offer it per project, and the SessionStart rules block now prints only when the project's output style is not Marvin's own. Install and upgrade also scan for plugins that inject a competing style and offer, never silently apply, a per-user disable in `.claude/settings.local.json`; the scan runs on every upgrade.

**The user-update check.** Every message to the user is checked against the update formats (U1-U4). By default (`update_gate: advise`) a note rides on your next prompt, with no extra turn. With `update_gate: block` a failing message is sent back once, with no loop, and the next prompt is advised as well. `off` disables the check. The rules are in `.marvin/agents/user-updates.md` (*Enforcement*).

**The sub-agent checks.** A sub-agent's final message that lacks a reserved line (`TRACKER:`, `GUARDRAILS:`, or one its brief reserves) or runs over 25 lines goes back to the agent once, and the corrected message reaches the parent. Every persona gets a constant rules block when it starts, and briefs are linted at dispatch.

**The context ladder.** At 70 / 80 / 90 % of the compaction window Marvin plans, winds down, then stops at a clean point and nudges you to `/compact`, or to a fresh session at an epic edge. The 400k and 700k session budgets share the ladder's wording and the stricter of the two speaks. The new `.marvin/agents/session-budget.md` owns the ladder.

**Acceptance.** On a scratch install of the local checkout (`claude -p --model haiku`, 2026-10-15): SubagentStop sent a `marvin:ponytail` final message missing `TRACKER:` and `GUARDRAILS:` back once and the corrected one reached the parent; the SubagentStart rules land as an attachment while the brief stays the agent's first user line; advise mode put the update note on the next prompt with no extra turn (2 Stops for 2 prompts); block mode blocked once, with no loop; the `marvin:marvin` style was selected with both competing style plugins disabled (0 Insight blocks); a haiku-driven install ran the competing-style finder and recorded its literal output.
