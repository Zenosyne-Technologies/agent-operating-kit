# v0.26.1 — the plugin manifest declares its licence

**A one-field patch.** marvin's `.claude-plugin/plugin.json` now carries `"license": "LicenseRef-PolyForm-Noncommercial-1.0.0"`. The LICENSE file has always been the authoritative licence — PolyForm Noncommercial 1.0.0, holder Emprove Services Kft. — and this simply declares the same in the manifest for tooling and discoverability, bringing marvin to parity with the token-telemetry manifest, which already declared it. There is no behaviour change, no installed-file change, and nothing to migrate.

**For consumers**: `upgrades/v0.26.1.md` is the whole upgrade — there is nothing to do beyond `claude plugin update marvin`.
