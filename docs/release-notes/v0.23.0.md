# v0.23.0 — guardrails, docblocks, and a license that ships with the install

**Agents get guardrails.** Until now a sub-agent's restraint lived only in the prose of whatever brief happened to mention it — so a persona about to do something destructive, out-of-scope or irreversible had no single place that told it to stop. This release adds `guardrails.md`: a "DO NOT" framework built on four dispositions (what is forbidden, what needs escalation, what is bounded, what is allowed), an escalation chain that says who a blocked agent turns to rather than pressing on, a generic baseline every persona inherits, and per-persona rows for the eight `marvin:*` roles. It is wired into the rules cascade, made an ingredient of every brief (with a reserved `GUARDRAILS:` line the agent's final message must carry), and cited from all eight personas. The point is not new capability but a bounded one: an agent that hits a guardrail escalates instead of improvising, and says so in a place the orchestrator reads.

**Builders now document the API surface.** `documentation-agent.md` item 2 gains a code-documentation convention: every new or modified public class or method carries a docblock stating its contract — summary, parameters, return, errors — in the language ecosystem's own idiom (PHPDoc, TSDoc, Javadoc, PEP 257 docstrings, rustdoc, GoDoc), never a kit-invented format. It is reconciled with the existing non-obvious-inline-comment rule so the two do not collide: a docblock states WHAT the contract is on the surface, an inline comment explains WHY a non-obvious line is the way it is. The two build personas cite it, so it applies at build time, not only at the documentation gate.

**Every install now carries its own license.** `templates/marvin/LICENSE` installs to `.marvin/LICENSE` — create-if-missing on install, seeded then kit-owned-refreshed on upgrade — so a project that adopts the kit has the licensing terms self-contained in its own tree rather than only in the factory repo. The license itself was made public earlier in this cycle: the kit is PolyForm Noncommercial 1.0.0 (a commercial license is reserved separately), and the copyright holder is the registered legal entity ZENOSYNE Kft. The installed copy is a verbatim copy of that notice, carried into installs so the terms travel with the payload.

**For consumers**: `upgrades/v0.23.0.md` is the whole upgrade. Nothing moves or is renamed, so this release ships no migration script — the refresh brings the new `guardrails.md` guide and the updated `documentation-agent.md`/`briefing.md`, one cascade row is merged into `CLAUDE.md` by hand, and `.marvin/LICENSE` is seeded.
