# v0.36.1 — the kit's CI test suites run on Linux again

No consumer-visible changes. Update the plugin with `claude plugin update marvin`; no upgrade run is needed.

The kit's CI had been red on `main` and `develop` since v0.33.0. The SessionStart-hook test T-RO simulated a host without `timeout` by dropping every PATH directory that held one — on Linux that removed `/usr/bin`, and with it `bash` itself. The mutation test M7 was timing-based and flaked on fast runners. Because that step failed, CI never ran the suites after it. T-RO now hides only `timeout` behind a shim directory and checks that it did; M7 now catches its mutant by output instead of elapsed time. The hook itself is unchanged.
