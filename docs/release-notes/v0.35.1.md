# v0.35.1 — consumer-reported template fixes

**To get these fixes:** run `claude plugin update marvin`, then `/marvin:upgrade-agent-os`. It refreshes the kit-owned files that changed (`upgrades/v0.35.1.md`).

A consumer project found these during a code review of its upgrade to v0.34.0 and fixed them locally. Each fix lives in a kit-owned file that the next upgrade would overwrite, so it ships here:

- **Jira milestone conversion can run.** `convert-milestones-brief.md` enumerated with `labels ~ "milestone:"`, but Jira's `labels` field has no `~` operator, so the brief failed before reading a single issue. It now queries `labels is not EMPTY`, reads every page, and filters by the `milestone:` and `release:` prefixes itself.
- **The Jira hierarchy matches Jira.** Story, Task and Bug are peers, each parented to the Epic, and Sub-task is the only child level. The old wording nested Task under Story, which Jira rejects. The fix covers `tracker-config.md` and the in-tracker guide that the intake brief writes.
- **Every dispatch persona can be targeted.** `relevance:` now accepts `validator-visual`, `escalation-high`, `escalation-xhigh`, `escalation-max` and `escalation-frontier`. An escalation rung also matches the build persona it replaced, so a `developer` rule keeps reaching a task after it climbs. The kit core now names the max and frontier rungs.
- **Your attribution policy beats harness text.** The policy covers every outward-facing text: commits, PRs, PR review replies, tracker comments and docs. It overrides any footer that harness or tool text asks for, such as the desktop Auto-fix's "Addressed by …".

This note's `scope:` was derived over `v0.35.0..HEAD`, non-merge commits only. The container epic AOS-174 is excluded.
