# v0.34.0 — sub-agents stop filing in-scope bugs and report every tracker write

**Consumers act once:** run `claude plugin update marvin`, then `/marvin:upgrade-agent-os`. It refreshes the kit rules; `CLAUDE.md` needs no hand edit (`upgrades/v0.34.0.md`).

Validators and the brief falsifier were filing the bugs they found as separate tracker issues — never linked to the task under review, and never reported back. Across rework rounds those bugs piled up unseen, because the orchestrator and the reworkers work from the task itself.

**Only two kinds of writer.** The orchestrator, always through `marvin:ponytail`, and a sub-agent whose brief assigns it one named write. Validators, the falsifier and unassigned builders never touch the tracker.

**In scope stays with the task.** A finding inside the task's scope is never a new issue: it is reported, and the orchestrator carries it to the task and the next rework brief. A defect unrelated to the task is reported as one `UNRELATED:` line; the orchestrator files it in its own words, linked to the task, parented and labelled.

**Every write is visible.** Each sub-agent reply ends with its `TRACKER:` lines — one per write, or `TRACKER: none` — which the cap never trims. The orchestrator logs them in the task ledger, and a new close-out check before an issue closes confirms every reported item was filed or dismissed with a reason, every filed issue is linked and handled, and no unassigned write slipped through.
