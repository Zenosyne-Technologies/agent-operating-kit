v0.43.1 — the documentation site

Consumers: no consumer-visible changes. Update the plugin; nothing to run in the project. See upgrades/v0.43.1.md.

Why. One hand-written docs/index.html could not carry the kit's growing surface, and the README had become the de facto manual. The site is now the canonical explanation, and most of it is generated from the repo, so it cannot drift from what ships.

What changed.

  • A static site at https://zenosyne-technologies.github.io/agent-operating-kit/: Home (a 30-second map), Getting started, concept pages (lifecycle with the persona inspector, sizing, escalation, around the loop, fleet), Mods, and generated Settings (every PROJECT-INFO.md key), Skills & commands, Reference (every guide's header) and a page per release.
  • Sources live in site/ (registry site/pages.json); scripts/build-docs.sh (stdlib Python, scripts/lib/build_docs.py) renders them into the committed docs/. A strict markdown subset fails loud on anything it does not know; links pass an allowlist; HTML is escaped.
  • Model and persona data on the site come from model-profile.md, model-profile-codex.md and agents/*.md; no model name is hand-typed in site/.
  • Rule-11 galleries: a mod page registered with feature shows the PNGs in docs/images/<feature>/ with one captions.md line each.
  • Emprove dark theme with self-hosted Montserrat and IBM Plex Mono (OFL, sources and sha256 recorded); visitors' browsers make no third-party requests. Old page anchors (#ladder, #stair, #signals, #lanes, #around, #insp) redirect to their new pages.
  • Factory: validate-kit check docs-site (26th) runs build-docs.sh --check (stale, missing or orphan output fails; the build prunes only output it owns and ignores OS metadata); marketplace scans every page under docs/ and site/; the test-build-docs suite (mutation-tested) runs in CI; README keeps the pitch, install, Documentation links, Contributing, Inventory and License; repo rules 8, 10 and 11 name the site in both CLAUDE.md and AGENTS.md.

Acceptance. Documentation, checked (repo rule 10):

  • README: inventory rows for scripts/build-docs.sh, scripts/lib/build_docs.py, scripts/test-build-docs.sh and site/; gate count twenty-six with docs-site in the list; suite count nineteen with the docs-site build suite listed; a Contributing paragraph on editing the site.
  • The site: every page regenerated by scripts/build-docs.sh on this branch; --check exit 0.
  • CLAUDE.md / AGENTS.md: rules 8, 10 and 11 updated identically (test-pinned).
  • No setting changed, so the PROJECT-INFO template and the install, upgrade and project-info skills are unchanged; site/settings-install.md documents the install-time keys.
  • docs/images/README.md describes captions.md and the feature registry key.
  • upgrades/v0.43.1.md and the CHANGELOG.md section.
  • Gates: validate-kit.sh all checks, every scripts/test-*.sh, and build-docs.sh --check, run on release/0.43.1. Each --check guard is mutation-tested inside test-build-docs.sh; no migration script changed, so mutate-migrations.sh does not apply.
  • Visual validation (marvin:validator-visual) of Home, Lifecycle, Settings, a release page and Mods at 1280 and 375: NOTES, 0 blocking. Self-hosted fonts load with no third-party request; there is no page-level sideways scroll; contrast meets AA; focus is visible; the inspector works by mouse and keyboard; #ladder and #insp redirect; there are no console errors. Seven advisory sev3/sev4 layout notes (the release sidebar at 375, the nav scroll cue, lifecycle diagram width and text size, and Settings code wrapping) are tracked in AOS-326.
  • Pending: live acceptance after Pages rebuilds main — the live root, every generated page and …/#ladder landing on Escalation.

Hand-offs: the queued epics' Pages work (AOS-295, AOS-287, AOS-273 and AOS-257) now targets site/ pages. Follow-ups: AOS-325, AOS-326, AOS-327.

This note's scope: was derived over v0.43.0..HEAD (git log --no-merges), AOS- prefixes deduplicated. The epic AOS-299 stays in scope because the whole-branch review fixes were committed under its key.

Upgrade

No consumer-visible changes.

  • Update the plugin; nothing to run in the project, no installed file changes, no new settings, no migration script.
  • The kit's documentation now lives on the GitHub Pages site (https://zenosyne-technologies.github.io/agent-operating-kit/): Getting started, the concept guides, a generated Settings, Skills & commands and Reference, and a page per release.

  • validate-kit check docs-site (26th) and the scripts/test-build-docs.sh suite, mutation-tested and run in CI.
  • Rule-11 screenshot galleries from docs/images/<feature>/captions.md; self-hosted Montserrat and IBM Plex Mono (OFL), so visitors' browsers make no third-party requests.

Changed

  • README slimmed to the pitch, install, contributing and the inventory; everything explanatory moved to the site.
  • Factory: repo rules 8, 10 and 11 (CLAUDE.md and AGENTS.md) name the site, site/, captions.md and the docs-site gate; validate-kit marketplace scans every page under docs/ and site/.
