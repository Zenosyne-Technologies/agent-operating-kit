v0.38.0 — hook-based rule enforcement

Consumers act once: run claude plugin update marvin, follow the update procedure the SessionStart notice prints (upgrades/v0.38.0.md).

The output style. A Marvin output style, marvin:marvin, carries the user-update rules in the model's system prompt. Install and upgrade offer it per project, and the SessionStart rules block now prints only when the project's output style is not Marvin's own. Install and upgrade also scan for plugins that inject a competing style and offer, never silently apply, a per-user disable in .claude/settings.local.json; the scan runs on every upgrade.

The user-update check. Every message to the user is checked against the update formats (U1-U4). By default (update_gate: advise) a note rides on your next prompt, with no extra turn. With update_gate: block a failing message is sent back once, with no loop, and the next prompt is advised as well. off disables the check. The rules are in .marvin/agents/user-updates.md (Enforcement).

The sub-agent checks. A sub-agent's final message that lacks a reserved line (TRACKER:, GUARDRAILS:, or one its brief reserves) or runs over 25 lines goes back to the agent once, and the corrected message reaches the parent. Every persona gets a constant rules block when it starts, and briefs are linted at dispatch.

The context ladder. At 70 / 80 / 90 % of the compaction window Marvin plans, winds down, then stops at a clean point and nudges you to /compact, or to a fresh session at an epic edge. The 400k and 700k session budgets share the ladder's wording and the stricter of the two speaks. The new .marvin/agents/session-budget.md owns the ladder.

Acceptance. On a scratch install of the local checkout (claude -p --model haiku, 2026-10-15): SubagentStop sent a marvin:ponytail final message missing TRACKER: and GUARDRAILS: back once and the corrected one reached the parent; the SubagentStart rules land as an attachment while the brief stays the agent's first user line; advise mode put the update note on the next prompt with no extra turn (2 Stops for 2 prompts); block mode blocked once, with no loop; the marvin:marvin style was selected with both competing style plugins disabled (0 Insight blocks); a haiku-driven install ran the competing-style finder and recorded its literal output.

This note's scope: was derived over v0.37.0..HEAD, non-merge commits only; the container epic AOS-204 is excluded.

Upgrade

Consumer-facing: Marvin's rules are now checked by plugin hooks, not only stated — user-update formats, sub-agent final messages, briefs, and a context ladder that stops the session cleanly before it fills. Rules: .marvin/agents/user-updates.md (Enforcement) and the new .marvin/agents/session-budget.md.

  • Update with the procedure the SessionStart notice prints. No file moves, so no migration script.
  • The upgrade adds .marvin/agents/session-budget.md; refreshes user-updates.md, briefing.md, model-profile.md and the kit core .marvin/CLAUDE.marvin.md (customised copies are backed up first); and adds update_gate: advise to .marvin/PROJECT-INFO.md.
  • It OFFERS — never silently applies — the Marvin output style ("outputStyle": "marvin:marvin" in .claude/settings.json) and, per competing style plugin found (e.g. explanatory-output-style), a disable for this project in .claude/settings.local.json (your machine only).
  • The competing-style scan runs on every upgrade, not only the first; the style is offered again whenever the project has none.
  • New plugin hooks: the user-update check (update_gate: advise | block | off), the sub-agent FINAL MESSAGE check, sub-agent rules injection, the brief lint, and the 70 / 80 / 90 % context ladder alongside the 400k / 700k budgets.
  • Start a new session after the upgrade so the hooks, the style and the rules load.

Changes

Added

  • A Marvin output style (marvin:marvin); install and upgrade offer it per project, and offer — never silently apply — a per-user disable of plugins that inject a competing style.
  • A user-update check on every message to the user: by default a note rides on your next prompt; update_gate: block sends a failing message back once and also advises on the next prompt; off disables it.
  • Sub-agent checks: a final message missing a reserved line (TRACKER:, GUARDRAILS:, or one its brief reserves) or over 25 lines goes back to the agent once; every persona gets a constant rules block; briefs are linted at dispatch.
  • A context ladder: at 70 / 80 / 90 % of the compaction window Marvin plans, winds down, then stops at a clean point and nudges you to /compact (or a fresh session at an epic edge).

Changed

  • The SessionStart rules block prints only when the project's output style is not Marvin's own.
  • The 400k / 700k session budgets now share the ladder's wording; the stricter of the two speaks.
  • Every upgrade re-runs the competing-style scan and offers the Marvin style when the project has none.
