v0.17.0

Upgrade

From v0.16.2 (the templates/pm/ regrouping is factory-side — installed projects see no file moves):

  1. ticket-filing.md: the coordinates hint gains the Local option — · Local → .docs/project-management/ + project key. Update the line; leave the resolved coordinates for this project as they are.
  2. Installs on pm_tool: none (legacy): offer the new Local tracker — a self-contained markdown tracker meeting the kit's 4 levels via files. On yes, install pm/local/'s tracker-config.md + stats-collection-brief.md to .docs/agents/, dispatch its intake-structure-brief.md (scaffolds .docs/project-management/ with INDEX.md, issues/, milestones/, guide.md), set the guide path in ticket-filing.md, and restamp pm_tool: local, hierarchy_levels: 4/4, project_key: <chosen key>. On no, nothing changes.
  3. Every other install (linear, jira, github): no consumer-visible changes beyond step 1.
