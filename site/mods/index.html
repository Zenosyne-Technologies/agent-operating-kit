Mods

A mod is something you see in Claude Code beside the chat: a pane, a sidebar, a band, a status line or a toast. Marvin ships a few mods so you can follow the work without reading every line of the transcript.

Two are planned. The questions sidebar is planned for v0.45.0, and the progress panel for v0.46.0 or later. Each will get its own page when it ships, with screenshots from a real session, and every mod page is listed in this section's sidebar.

  • Questions sidebar (planned for v0.45.0): the questions Marvin is waiting on, kept in view while it works.
  • Progress panel (planned for v0.46.0 or later): where the current run stands.
