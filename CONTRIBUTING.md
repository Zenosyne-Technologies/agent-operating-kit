## Contributor license grant (please read before opening a PR)

GitHub's default is that contributions arrive under the project's public
license only. That would leave any code you contribute available for
non-commercial use *only* — and the copyright holder could not include it in a
commercial license. To keep the dual-license model workable, contributions here
carry an explicit grant.

repository), you agree that:

If you cannot make this grant — for example, your employer owns your work, or
your contribution is under an incompatible license — **do not submit it**. Open
an issue to discuss instead.

## Sign your commits

Certify the DCO by signing off each commit:

```
git commit -s -m "AOS-123: your message"
```

`-s` appends a `Signed-off-by: Your Name <you@example.com>` line, which is your
statement that the DCO below applies to that commit. (Commit messages start with
the tracker issue key, per the project's own convention.)
