# v0.26.0 — /marvin:play scenarios, the licence holder becomes Emprove, and a no-local-paths gate

Nothing moves or is renamed, so there is no `migrate-v0.26.0.sh` — the steps below are the whole upgrade. As on every release, the kit-owned guides in `.marvin/agents/` and `.marvin/LICENSE` are re-rendered from the current templates; anything replaced is backed up to `.marvin/backups/v0.26.0/`, reconcile customisations from there. (0.25.0 was reserved for Milestone E and skipped; this is the release after v0.24.0.)

1. **The `/marvin:play` scenarios ship WITH the plugin, not as installed files.** Run `claude plugin update marvin` to get `/marvin:play <scenario>` — a bounded, self-terminating dispatcher for `research-solo`, `research-deep`, `quick-fix`, `taskforce`, and `bug-hunt`. Nothing to merge into `CLAUDE.md`; they run in sub-agent mode today (agent-teams behaviour arrives with a later Milestone E).
2. **`.marvin/LICENSE` now names Emprove Services Kft.** The refresh above re-renders your installed licence notice — holder Emprove Services Kft. (maintained by Zenosyne Kft.), PolyForm Noncommercial 1.0.0 body unchanged. If you customised it, reconcile from the backup.
3. Restamp `.marvin/PROJECT-INFO.md`: `kit_version: 0.26.0`.
