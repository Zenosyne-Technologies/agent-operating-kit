# v0.39.0 — host tidying and ticket-filing standards

Consumer-facing: **agents now label and clean up their Docker resources, run throwaway databases without binary logging, and file tracker items with every required label.** Rules: `.marvin/agents/tidying.md` and `.marvin/agents/ticket-filing.md`.

- Update with the procedure the SessionStart notice prints. No file moves, so no migration script.
- The upgrade adds `.marvin/agents/tidying.md`; refreshes `label-syntax.md` (v1.5.0), `ticket-filing.md`, `ponytail.md`, `worktrees.md`, `guardrails.md`, `briefing.md` and the kit core `.marvin/CLAUDE.marvin.md` (customised copies are backed up first); and adds `ticket_lint: block` to `.marvin/PROJECT-INFO.md`.
- It re-dispatches the tracker's intake brief: a guide refresh plus a report-only label audit of every open item. It then asks ONE yes/no on backfilling the flagged items; on no, they are only reported.
- New plugin hooks: the Docker sweep (session start and `/marvin:clean-worktrees`), the Docker lint (advises on unlabelled resources, compose stacks without a project name, and throwaway MySQL/MariaDB with binary logging on) and the ticket lint (`ticket_lint: block | advise | off`; project's own tracker only).
- Label your Docker resources per `tidying.md` (`marvin.project`, `marvin.checkout`, `marvin.owner`, `marvin.lifetime`). Resources created before this upgrade carry no labels and are never swept, so remove them by hand.
- **Start a new session after the upgrade** so the hooks and rules load.
