# v0.38.0 — hook-based rule enforcement

Consumer-facing: **Marvin's rules are now checked by plugin hooks, not only stated** — user-update formats, sub-agent final messages, briefs, and a context ladder that stops the session cleanly before it fills. Rules: `.marvin/agents/user-updates.md` (*Enforcement*) and the new `.marvin/agents/session-budget.md`.

- Update with the procedure the SessionStart notice prints. No file moves, so no migration script.
- The upgrade adds `.marvin/agents/session-budget.md`; refreshes `user-updates.md`, `briefing.md`, `model-profile.md` and the kit core `.marvin/CLAUDE.marvin.md` (customised copies are backed up first); and adds `update_gate: advise` to `.marvin/PROJECT-INFO.md`.
- It OFFERS — never silently applies — the Marvin output style (`"outputStyle": "marvin:marvin"` in `.claude/settings.json`) and, per competing style plugin found (e.g. `explanatory-output-style`), a disable for this project in `.claude/settings.local.json` (your machine only).
- The competing-style scan runs on every upgrade, not only the first; the style is offered again whenever the project has none.
- New plugin hooks: the user-update check (`update_gate: advise | block | off`), the sub-agent FINAL MESSAGE check, sub-agent rules injection, the brief lint, and the 70 / 80 / 90 % context ladder alongside the 400k / 700k budgets.
- **Start a new session after the upgrade** so the hooks, the style and the rules load.
