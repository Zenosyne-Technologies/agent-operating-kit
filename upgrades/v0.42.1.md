# Upgrade to v0.42.1

Consumer-facing: **fleet-mode follow-ups and two small fixes — no surface removed or renamed.**

- Update the plugin, then run `/marvin:upgrade-agent-os` once. It refreshes `fleet.md`, `fleet-child.md`, `session-budget.md`, `git-strategy.md`, `worktrees.md` and the kit core `CLAUDE.marvin.md`.
- If `.marvin/PROJECT-INFO.md` has a free-text value (`brief`, `description`, `owner`, `stack`, `dev_command`, `tracker_coordinates`, `project`) holding `: ` or ` #` unquoted, run `/marvin:project-info`: it validates the frontmatter and wraps such values in double quotes. New installs write them quoted.
- Fleet users: a master's own handoff now goes into the program plan's **Handoff** section (add it to an existing plan; the master does so at its next rest point), and a child that finds the master marker gone on resume asks the architect before continuing. Tell running children to stop (`fleet-child.md`) before `/marvin:fleet stop`.
- `/marvin:info` now reports a fleet marker (role, age); a `role=master` marker with no fleet running is stale and `/marvin:fleet stop` clears it.
- No migration script, no new settings.
