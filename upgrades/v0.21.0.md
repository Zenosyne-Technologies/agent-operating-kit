does not create the destination's parent (exit 128 otherwise). Idempotent, but ONLY if each step is
gated on `git ls-files --error-unmatch <source>`: a filesystem test is wrong, because `INDEX.md` and
`index.md` are the same inode on macOS, so `[ -f …/index.md ]` is true before the rename runs.

2. `git mv .docs/PROJECT-INFO.md .marvin/PROJECT-INFO.md`.

4. Per audience, via a temp name: `.docs/handbooks/<audience>/INDEX.md` → `index.md`. Confirm with
   `git ls-files`, not `ls` — `ls` still prints the old casing.
5. Rewrite every stale `.docs/agents/`, `.docs/PROJECT-INFO.md`, `.docs/marvin/` and handbook
   `INDEX.md` reference in `CLAUDE.md` and the migrated files.
