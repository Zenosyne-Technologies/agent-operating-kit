# v0.37.0 — agent worktree cleanup and push cadence

Consumer-facing: **finished agent worktrees are removed automatically, and agents push done work often** so no cleanup can lose it. Rules: the new `.marvin/agents/worktrees.md`.

- Update with the procedure the SessionStart notice prints. No file moves, so no migration script. Upgrade promptly: the personas and the sweep ship with the plugin, so they act as soon as it updates, even before `worktrees.md` is installed.
- The upgrade adds `.marvin/agents/worktrees.md` and refreshes `git-strategy.md`, `briefing.md`, `guardrails.md` and the kit core `.marvin/CLAUDE.marvin.md` (customised copies are backed up first). It also adds `.claude/worktrees/` to `.gitignore`.
- New plugin hook: at session start the sweep removes a worktree under `.claude/worktrees/` only when seven guards hold: unlocked, not in use, nothing else inside it, idle 15 minutes, no merge or rebase in progress, clean, and merged into another branch. Prunable entries are reported, never touched.
- It deletes the local branch only when origin's copy contains the worktree's commits; otherwise the branch is kept and reported. `/marvin:clean-worktrees [--check]` runs it on demand.
- Every sub-agent that commits work, the documenter and ponytail included, pushes its own branch and ends with a `WORKTREE:` line; the orchestrator pushes the parent after each merge. With no remote configured, pushes are skipped and reported.
- Accepted limit: a quiet interactive `--worktree` or desktop session standing in a clean, merged worktree under `.claude/worktrees/` can be swept by another session's sweep.
- **Start a new session after the upgrade** so the hook, the skill and the rules load.
