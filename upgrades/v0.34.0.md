# v0.34.0 — sub-agents stop filing in-scope bugs and report every tracker write

Consumer-facing: **who may write to your tracker changes.** Only the orchestrator (through `marvin:ponytail`) or a sub-agent whose brief assigns it one named write may create, comment on, transition, label or link issues.

- `claude plugin update marvin`, then run `/marvin:upgrade-agent-os` — it refreshes `.marvin/CLAUDE.marvin.md` (the lifecycle gains a close-out check before an issue closes) and `ticket-filing.md`, `briefing.md`, `validation-agent.md`, `visual-validation.md`, `planning-research.md`, `documentation-agent.md`, `ponytail.md`, `security.md` (customised copies backed up first). No hand edit of `CLAUDE.md`.
- A finding inside the task's scope is never filed as a new issue — it is reported and carried to the task. An UNRELATED defect is reported as an `UNRELATED:` line; the orchestrator files it, linked to the task, parented and labelled.
- Every sub-agent reply ends with its `TRACKER:` lines (one per write, or `TRACKER: none`); the orchestrator records them in the task ledger and carries open items into the next rework brief.
- Before a task closes, the close-out check confirms every reported item was filed or dismissed with a reason, every filed issue is linked and addressed or deferred, and no unassigned tracker write went unnoticed.

This note's scope was derived over `v0.33.0..HEAD`, non-merge commits only; the container epic AOS-145 is excluded.
