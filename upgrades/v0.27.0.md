# v0.27.0 — greenfield brief-first interview + a third attribution option

Consumer-facing, but only for **new greenfield installs**; existing installs are unaffected and there is nothing to do.

- The greenfield install interview now asks **what you are building** (a short project brief) as its FIRST question — before target audience, size, app type and tech stack — so the stack suggestion reasons from the brief instead of being offered blind. The brief is saved as `brief:` in `.marvin/PROJECT-INFO.md`.
- The install's attribution question now offers a **third option, "Emprove Marvin (Claude)"** — a branded commit/PR trailer — alongside keeping the default attribution and disabling it.

Existing installs: `claude plugin update marvin` picks up the new templates, but nothing changes in an already-installed project — the interview runs only at install, and `PROJECT-INFO.md`/`settings.json` are never overwritten on upgrade.
