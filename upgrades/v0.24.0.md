# v0.24.0 — greenfield installs interview and scaffold; the docs estate becomes self-contained

Nothing moves or is renamed, so there is no `migrate-v0.24.0.sh` — the steps below are the whole upgrade. As on every release, the kit-owned guides in `.marvin/agents/` are re-rendered from the current templates and anything replaced is backed up to `.marvin/backups/v0.24.0/`; reconcile customisations from there.

1. **The docs estate is now self-contained.** The refresh updates `.marvin/agents/document-standard.md` with the one-way-dependency rule: a `.marvin/` guide may point into `.docs/`, but a `.docs/` document never references `.marvin/`. Your OWN `.docs/` seeds are NOT overwritten, so they may still cite `.marvin/`; to make them self-contained (so `.docs/` can be shared without exposing the agent machinery), drop the `.marvin/` pointers from each `index.md` by hand or re-render from `templates/docs/`.
2. **New installs interview and can scaffold; existing projects are unaffected.** The greenfield interview (audience, size, app type, tech stack) and the optional "Milestone 0" scaffolding live in the install skill and apply only to fresh installs. To record the new facts on an existing project, add `audience`, `project_size` and `app_type` to `.marvin/PROJECT-INFO.md`.
3. **Marvin's persona nudge is optional to adopt.** `CLAUDE.md` is yours and is not overwritten; to pick up the sharper, skeptical persona, copy the "You are Marvin" paragraph from the current `CLAUDE.core.md`.
4. Restamp `.marvin/PROJECT-INFO.md`: `kit_version: 0.24.0`.
