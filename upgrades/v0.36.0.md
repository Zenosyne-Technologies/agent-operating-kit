# v0.36.0 — Claude 5.5 routing, safe-update procedure, what's-new

Consumer-facing: **Marvin targets the Claude 5.5 family.** Fully-specified small builds and corrections run on a new micro-tier developer (Haiku 5.5, high effort); judgement work stays on Sonnet 5.5; a stuck small-tier build gets one Sonnet xhigh rung before the Opus rungs. All Sonnet and Haiku personas (`marvin:developer-small`, `marvin:documenter`, `marvin:developer-micro`, `marvin:ponytail`) are now pinned to high effort.

- Update with the procedure the SessionStart notice prints (it states the order and when to start a new session); then run `/marvin:upgrade-agent-os`.
- No file moves — no migration script. Refreshed guides (customised copies backed up first): `model-profile.md`, `briefing.md`, `escalation.md`, `escalation-ladder.md`, `guardrails.md`, `planning-research.md`, `token-economics.md`, `information-guide.md`; the kit core `.marvin/CLAUDE.marvin.md` is refreshed too. No tracker or label change.
- Session breaks now follow context size (plugin hook, advisory, never blocks): 400k soft / 700k hard tokens. Override with `session_soft_ktokens` / `session_hard_ktokens` (integers, thousands, soft < hard) in `.marvin/PROJECT-INFO.md` frontmatter. The kit core no longer asks for a fresh session at every milestone close; it does only when no plugin hook runs.
- If your `.docs/information/` files use `relevance:`, the new legal values are `developer-micro` and `escalation-small-xhigh`.
- **Start a new session after the upgrade** so the new personas, rules and hooks load.
- Ask `/marvin:whats-new` for the categorised list of what changed since your version.
