# v0.35.0 — reports move from .docs/reports/ to .marvin/reports/

Consumer-facing: **reports are Marvin's records, not project docs.** Stats snapshots, digests, milestone close-outs and install/upgrade reports now live in `.marvin/reports/` (still committed).

- `claude plugin update marvin`, then run `/marvin:upgrade-agent-os`. After the split question (v0.33.0), it runs `scripts/migrate-v0.35.0.sh` first: every file under `.docs/reports/` moves to the same path under `.marvin/reports/`, including hand-written ones, committed as its own step.
- **If the move is blocked** — untracked or ignored files (even `.DS_Store`) in `.docs/reports/`, a destination collision, a symlink, or an unsafe repo state — the upgrade STOPS: it commits only its report naming the blocker and does not restamp. Clear it (commit or remove), then re-run the upgrade.
- Rows in your `.docs/index.md` that pointed at `reports/` are removed or retargeted by the upgrade and listed in its report.
- Refreshed guides: `briefing.md`, `document-standard.md`, `reporting.md` and your tracker's `stats-collection-brief.md` (customised copies backed up first). No hand edit of `CLAUDE.md`.

This note's scope was derived over `v0.34.0..HEAD`, non-merge commits only; the container epic AOS-164 is excluded.
